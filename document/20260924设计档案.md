## 一、目标与非目标

### 目标

1. 一个默认的**通用聊天 CLI**，能用 `deepseek-flash` 流式聊天，聊任何话题。
2. 保留 **anima / minimax 提示词后处理管道**，作为独立入口，不污染聊天逻辑。
3. 共用底层能力：API 调用、token 日志、成本统计、配置。
4. 配置外置，模型名、价格、阈值、默认参数都能改，不用动代码。
5. 多会话管理：新建、列表、加载、重命名、保存。
6. 思考模式可切换，`reasoning_effort` 可切换。
7. 结构清晰，以后加功能（智能体、多模态、摘要）不用推翻重写。

### 非目标（这一版不做）

1. 本地模型支持（Ollama / vLLM / LM Studio）。
2. 图片聊天（`/reverse` 只留在后处理管道，聊天不做）。
3. 函数调用 / 工具 / 联网 / RAG。
4. Web UI。
5. 数据库存储（先用 JSONL）。
6. 多用户、权限、云端同步。

## 二、API 选择决定

**决定：使用 Chat Completions，但客户端层做成可替换。**

理由：

- DeepSeek 官方文档明确展示 Chat Completions，兼容性最有保障。
- 你现有脚本就是它，迁移成本最低。
- 未来智能体需求，Chat Completions 本身支持 Tool Calls，足够用。
- 如果以后真要切 Responses API，只改 `core/client.py`，上层不动。

这个决定不再需要你过问。

- **聊天与后处理不共享对话上下文**：各走各的。

## 五、核心模块设计

### 5.1 `core/config.py`

**职责**：集中所有配置，从 `key.env` 和环境变量读取，提供默认值。

**配置项清单**：

```python
@dataclass
class Config:
    # API
    api_key: str
    base_url: str = "https://api.deepseek.com"
    model: str = "deepseek-flash"

    # 默认生成参数
    temperature: float = 0.7
    max_tokens: int = 8192

    # 思考模式
    thinking_enabled: bool = True
    reasoning_effort: str = "low"   # low / high / max

    # 流式
    stream: bool = True

    # 上下文管理
    max_context_tokens: int = 128000   # 本地裁剪阈值，远低于 1M
    keep_recent_rounds: int = 20       # 硬截断时保留最近多少轮
    warn_context_tokens: int = 64000   # 软警告阈值

    # 价格（元/百万 token，空闲时段，缓存未命中）
    price_input: float = 1.5
    price_output: float = 4.5

    # 路径
    base_dir: Path
    sessions_dir: Path
    history_dir: Path
    token_log_file: Path
```

**加载方式**：

```python
def load_config() -> Config:
    base_dir = Path(__file__).resolve().parent.parent
    load_dotenv(base_dir / "key.env")
    # 从环境变量覆盖
    ...
```

**关键点**：

- `load_dotenv` 用脚本目录，不用当前工作目录。
- 所有配置有默认值，环境变量可选覆盖。
- 价格以后你按实际账单改 `key.env` 即可。

### 5.2 `core/client.py`

**职责**：封装 DeepSeek API 调用，提供流式和非流式两种方法。

**对外接口**：

```python
class DeepSeekClient:
    def __init__(self, config: Config):
        self.client = OpenAI(
            api_key=config.api_key,
            base_url=config.base_url,
            timeout=60,
            max_retries=2,
        )
        self.config = config

    def chat(self, messages: list[dict], **overrides) -> dict:
        """非流式调用，返回 {content, reasoning, usage}"""

    def stream_chat(self, messages: list[dict], on_delta, **overrides) -> dict:
        """
        流式调用。
        on_delta(event_type, text) 回调，event_type 为 'reasoning' 或 'content'。
        返回 {content, reasoning, usage}。
        """

    def build_params(self, **overrides) -> dict:
        """合并默认参数和临时覆盖。"""
```

**流式处理细节**：

```python
stream = self.client.chat.completions.create(
    model=self.config.model,
    messages=messages,
    stream=True,
    temperature=...,
    max_tokens=...,
    reasoning_effort=self.config.reasoning_effort,
    extra_body={"thinking": {"type": "enabled" if self.config.thinking_enabled else "disabled"}},
    stream_options={"include_usage": True},
)

reasoning = ""
content = ""
usage = None

for chunk in stream:
    if chunk.usage:
        usage = chunk.usage
    if not chunk.choices:
        continue
    delta = chunk.choices[0].delta
    if delta.reasoning_content:
        reasoning += delta.reasoning_content
        on_delta("reasoning", delta.reasoning_content)
    if delta.content:
        content += delta.content
        on_delta("content", delta.content)

return {"content": content, "reasoning": reasoning, "usage": usage}
```

**错误处理**：

- 超时、限流、5xx：打印友好提示，返回 `None` 或抛自定义异常。
- 流中断：已收到的内容保留，提示“输出中断”。
- Ctrl+C：中断流，保留已收到内容。

### 5.3 `core/session.py`

**职责**：会话的创建、加载、保存、列表、重命名、删除。

**数据格式**：

`sessions/index.jsonl` 每行一条：

```json
{"id": "20260924_143022_abc1", "title": "新会话", "created": "2026-09-24T14:30:22", "updated": "2026-09-24T14:35:10", "mode": "chat", "model": "deepseek-flash"}
```

`sessions/<id>.jsonl` 每行一条消息：

```json
{"role": "system", "content": "你是一个乐于助人的 AI 助手。", "ts": "..."}
{"role": "user", "content": "你好", "ts": "..."}
{"role": "assistant", "content": "你好，有什么可以帮你？", "ts": "...", "reasoning": "..."}
```

**接口**：

```python
class Session:
    id: str
    title: str
    mode: str
    model: str
    system_prompt: str
    messages: list[dict]   # 不含 system，system 单独存
    created: datetime
    updated: datetime
    usage: dict            # 累计 token

class SessionManager:
    def list_sessions(self) -> list[dict]
    def new_session(self, mode="chat", model=None, system_prompt=None) -> Session
    def load(self, session_id: str) -> Session
    def save(self, session: Session) -> None
    def rename(self, session_id: str, title: str) -> None
    def delete(self, session_id: str) -> None
```

**关键点**：

- system prompt 单独存字段，不塞进 `messages`，调用时再拼。
- 每条消息带时间戳，方便排序和展示。
- assistant 消息可选存 `reasoning`，方便回看。
- 会话文件坏了一条，不影响其他会话。

### 5.4 `core/token_log.py`

**职责**：记录每次 API 调用的 token，提供统计和成本估算。

**数据格式**：`token_log.jsonl` 每行：

```json
{"ts": "...", "session_id": "...", "mode": "chat", "model": "deepseek-flash", "prompt_tokens": 100, "completion_tokens": 200, "reasoning_tokens": 0, "total_tokens": 300, "cost": 0.0012}
```

**接口**：

```python
def log_call(session_id, mode, model, usage, config) -> None
def summarize(days=7) -> dict
def session_cost(session_id) -> float
def estimate_cost(prompt_tokens, completion_tokens, config) -> float
```

**关键点**：

- 成本按配置价格算，缓存命中/未命中暂不区分，以后可加。
- 启动时显示最近 7 天统计。

## 六、聊天模块

### 6.1 `chat/main.py`

**职责**：聊天主循环。

**流程**：

```text
启动
  ├── 加载配置
  ├── 显示 banner
  ├── 显示最近 token 统计
  ├── 加载最近会话或新建
  └── 进入循环

循环
  ├── 读取输入
  ├── 如果是命令 → commands.handle()
  ├── 如果是普通输入
  │   ├── 拼 messages = [system] + session.messages + [user]
  │   ├── 上下文裁剪（按 token 或轮数）
  │   ├── 调用 client.stream_chat()
  │   ├── 流式输出
  │   ├── 加入 session.messages
  │   ├── 保存会话
  │   ├── 记录 token
  │   └── 显示统计
  └── 循环
```

**上下文裁剪策略**：

1. 先算当前 `messages` 估算 token。
2. 超 `max_context_tokens` 时：
   - 保留 system。
   - 从最旧的非 system 消息开始丢弃。
   - 直到低于阈值。
3. 显示提示：“已裁剪 N 轮旧对话以控制上下文”。

**`/trim` 命令**：手动保留最近 N 轮。

## 七、后处理管道模块

### 7.1 `pipeline/runner.py`

**职责**：统一运行 anima / minimax 后处理。

**接口**：

```python
@dataclass
class PipelineResult:
    output: str
    usage: dict | None
    errors: list[str]
    blocks: dict | None   # anima 的 global/post/negative

PIPELINES = {
    "anima": AnimaPipeline,
    "minimax": MinimaxPipeline,
}

def run_pipeline(mode: str, user_input: str, context: list | None = None) -> PipelineResult:
    ...
```

**流程**：

```text
输入
  ├── 取 system prompt
  ├── 拼 messages
  ├── 调用 client.chat()（非流式）
  ├── 校验输出
  ├── 拆分区块（anima）
  ├── 记录 token
  ├── 写 markdown 归档
  └── 返回结果
```

**CLI 入口**：

```bash
python -m deepseek_tool.pipeline.runner --mode anima
python -m deepseek_tool.pipeline.runner --mode anima --input "简短描述"
python -m deepseek_tool.pipeline.runner --mode anima --file desc.txt
python -m deepseek_tool.pipeline.runner --mode minimax
```

交互模式下，可以连续输入多条，每条独立处理，不共享上下文（除非加 `--context`）。

### 7.2 `pipeline/anima.py`

**内容**：

- `ANIMA_SYSTEM`（你原来的完整 system prompt）
- `split_anima_blocks(text)`
- `count_tags(block_text)`
- `validate_anima(text) -> list[str]`（原 `validate_output` 的 anima 部分）
- `ANIMA_BLOCK_PATTERNS`
- `POST_FIELD_BLACKLIST`
- `FRAMING_TAGS`

**校验项**：

- 三个区块存在
- 主体数量
- 安全标签唯一
- 质量前缀
- 禁止词
- 密度（全局/后期 >= 8，负面 3~12）
- 后期字段名
- 取景标签加权
- 光影六要素（轻量）

---

### 7.3 `pipeline/minimax.py`

**内容**：

- `MINIMAX_SYSTEM`
- `validate_minimax(text) -> list[str]`（原 `validate_output` 的 minimax 部分）

**校验项**：

- 安全标签
- 主体数量
- 时间线 >= 3 段
- 声音设计 >= 3 类
- 景别、镜头角度、运镜
- 禁止词

## 十、流式输出设计

### 输出效果

```text
（暗色斜体）思考中... 用户问的是天气，我需要...
（正常颜色）今天温州天气晴，气温 22~28℃...
```

### 实现

- `reasoning`：用 `dim italic` 样式，或折叠为一行“思考中...（/thinking show 展开）”。
- `content`：正常输出，边收边打印。
- 默认只显示 `content`，`reasoning` 折叠。`/thinking show` 可展开。
- 流结束后，换行，显示统计。

### 中断处理

- Ctrl+C：中断流，保留已收到内容，提示“输出中断，已保存部分内容”。
- 网络错误：保留已收到内容，提示错误，可选择重试。

## 十一、上下文管理

### 裁剪策略

1. system prompt 单独存，不参与裁剪。
2. 每次调用前估算 `messages` token。
3. 超过 `max_context_tokens`：
   - 从最旧的非 system 消息开始丢弃。
   - 丢弃到低于阈值。
4. 显示提示：“已裁剪 N 轮旧对话”。

### token 估算

- 简单估算：字符数 / 2（中英混合粗略）。
- 或调用 API 的 tokenizer（如果 SDK 提供）。
- 先粗估，够用。

### 长对话策略（未来）

- `/compact`：调用模型摘要旧对话，替换为摘要。
- 这一版不做，留接口。

## 十二、错误处理

| 场景 | 处理 |
|---|---|
| API key 缺失 | 启动时提示，退出 |
| 超时 | 提示，保留已收内容，可重试 |
| 限流 429 | 提示，建议稍后 |
| 5xx | 提示，建议重试 |
| 流中断 | 保留已收内容，提示 |
| Ctrl+C | 中断，保留已收内容 |
| 会话文件损坏 | 跳过该条，提示 |
| 校验失败 | 后处理模式警告，聊天模式不校验 |
